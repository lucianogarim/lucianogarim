<table>

### 🧠 Geochemically Informed ML
Models that embed geochemical constraints into the architecture and the loss function, instead of treating rock data as generic tables.

Generative Adversarial Networks and Variational Autoencoders for data augmentation and log reconstruction on imbalanced datasets.

</td>

## 🚀 Featured Projects

- 🧬 **[ChemoGAN](https://github.com/lucianogarim/ChemoGAN):** code and experiments for the ChemoGAN paper, on generative models for chemostratigraphic data.
- 🧪 **[cgan-ecs-mg-presalt](https://github.com/lucianogarim/cgan-ecs-mg-presalt):** conditional GAN experiments for elemental capture spectroscopy logs in pre-salt reservoirs.
- 🪨 **[Classificacao-de-Eletrofacies](https://github.com/lucianogarim/Classificacao-de-Eletrofacies):** electrofacies classification from seismic attributes trained on well data.
- 📈 **[arvores_regressao_porosidades](https://github.com/lucianogarim/arvores_regressao_porosidades):** porosity prediction with regression trees and seismic attributes, applied to the Sapinhoá Field.
- ⚙️ **ContinentalAllPlugin:** stratigraphic simulator for carbonate rocks based on fuzzy logic. Software registered with the Brazilian Patent Office (INPI) under BR512024003047-6, funded by Petrobras.
